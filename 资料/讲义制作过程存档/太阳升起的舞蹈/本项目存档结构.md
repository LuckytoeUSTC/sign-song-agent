# 本项目存档结构

本文件只说明《太阳升起的舞蹈》存档中的目录结构和文件作用。

## 稿件与参考材料

| 目录 | 文件作用 |
|---|---|
| LLM-demo | 保存早期转写稿、拓宽稿及其中的人工纠正。 |
| 中间稿 | 保存贴图工作稿与历次修订稿，供对照修改前后的内容。 |
| reviewed | 保存组长批阅稿及原生 Word 批注。 |
| teacher-remarked | 保存 A、B 两版教师备注稿；B 版为当前主要参照。 |
| final | 保存 A、B 两版打印稿；B 版为当前主要参照。 |
| 参考材料 | 保存秘鲁手语手册、动作视频、日出图片和缘分等参考原件。 |
| 转写修改与辨析案例 | [.content](转写修改与辨析案例/.content) 列出案例编号与正文链接；每个修改案例一个 Markdown 文件，记录何时参考、核心辨析、修改经过、老师理由和原件位置。 |

## 说明与记录

| 文件 | 文件作用 |
|---|---|
| [本曲转写规则.md](本曲转写规则.md) | 保存只适用于本曲的转写规则及对应案例。 |
| [本次讲义格式要求.md](本次讲义格式要求.md) | 保存本次讲义的排版、选图和制作要求。 |
| [候选词条.md](候选词条.md) | 保存本曲查询国家通用手语词典时得到的候选词条、动作文字和图片资源位置；不是最终采用清单。 |
| [对话记录.md](对话记录.md) | 保存备课过程中的原始文字讨论，供追溯老师原话和修改理由。 |
| 本项目存档结构.md | 说明本项目各目录与文件的作用。 |
