# 资料说明

这里保存备课参考原件、讲义合作记录，以及从原件提取的表达和修改案例。原件各保留一份；提取内容须注明来源文件与具体位置，不替代原件。

## 目录用途

| 文件夹 | 保存内容 | 怎样使用 |
|---|---|---|
| 教材 | 手语教材原资料，包括句子、会话和语言知识 | 查表达的上下文与教材位置；没有作者解释时，不把AI分析当作教材结论 |
| 小班讲义 | 手语小班的教学讲义 | 学习歌词画面、手语语序、动作表达及讲义制作方法 |
| 优秀讲义 | 已有歌曲讲义原件 | 参考具体转写、图词对应和排版；单独一个表达不代表发生过修改 |
| 讲义制作过程存档 | 按歌曲保存的对话、各阶段稿件、人工批阅、老师备注稿及打印稿 | 对照一次讲义如何形成，查老师的选择与理由；每首歌的目录和文件作用见其本项目存档结构 |
| 规则与例句数据库 | 转写例句表、修改辨析正文及其检索目录 | 查转写例句，或比较实际修改方案；每条记录指向来源及具体位置 |

[资料目录.xlsx](资料目录.xlsx)记录教材、小班讲义、优秀讲义及讲义制作过程存档中的完整讲义、修改稿、反馈表、教材和特殊语言词典，包含日期、作者／授课老师、修订者、资料类型、版本／用途和文件链接。一份文件一行，日期未提供的留空，不使用文件时间推断。资料说明、格式要求、候选词条等工作说明不作为原始资料条目。

原句与转写记录只说明“原作者这样表达”；修改辨析须有实际前后方案或明确的修改讨论，并保留老师的理由及出处。辨析目录只放简短检索信息和正文入口，不重复保存Markdown全文。

定位时区分PDF页码、Word正文段落和教材整理文本行号。Word正文段落数包含空段，不是打印页码；PDF提取可能丢失斜体、删除线和图示，需要结合原页核对。

## 规则与例句数据库

此目录保存公共转写规则、检索表和数据库使用方法：

- [公共转写规则.md](规则与例句数据库/公共转写规则.md)：小班经验的提炼、具体案例、不同用法及适用边界。合作产生的新归纳由老师裁定为通用、本歌曲、待议或不采用。
- [转写例句.xlsx](规则与例句数据库/转写例句.xlsx)：教材、小班和优秀讲义的原句、转写、关联规则及出处。教材会话完整轮次在同一文件的“会话上下文”页保存，主表保留当前轮次附近语境。
- [转写修改与辨析目录.xlsx](规则与例句数据库/转写修改与辨析目录.xlsx)：修改辨析的编号、原句、何时参考、核心辨析、关联规则、歌题及正文链接。目录由各案例开头的引导自动生成，完整理由及出处只在案例Markdown维护。

原句与转写表可由AI通过`scripts/search_cases.py`检索。查看结果时按来源和位置回看原件，尤其动作方向、非手控、斜体、删除线及图示选择。


资料目录只收录完整讲义、讲义修改稿、反馈表、教材和特殊语言词典等成套资料。图片、视频、零散动作参考和原始对话记录留在项目存档内，不单列进资料目录。

[规则与例句查询](规则与例句查询.html)是轻量离线查阅入口，资料仍在规则与例句数据库及讲义制作过程存档中维护。
