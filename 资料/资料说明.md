# 资料说明

查找整份讲义、教材、修改稿或反馈表，打开[资料目录](资料目录.xlsx)；查一句话怎么转写、为什么这样改，打开[规则与例句查询](规则与例句查询程序.pyw)。

## 资料放在哪里

| 内容 | 位置与用途 |
|---|---|
| 教材 | `教材`：查词句、会话和语言知识 |
| 小班讲义 | `小班讲义`：参考入门教学与课堂练习 |
| 手语歌讲义 | `手语歌讲义／歌名`：参考整首歌的转写、图解与排版 |
| 讲义制作过程 | `讲义制作过程存档／歌名`：查看各版稿件、批阅和修改理由 |
| 转写规则、例句与辨析 | `规则与例句数据库`：比较表达、查阅案例和审核规则 |

资料目录包含成套资料的作者、日期、版本与原件链接。零散图片、视频和动作参考保留在对应项目中，不单列进资料目录。

[手语基础教程（第二版）](<教材/手语基础教程（第二版）.pdf>)供查阅句子与完整会话。现有文件是整理文本转换的19页PDF，查询中的页码指此文件，不是原书页码。

## 歌曲讲义与制作过程

歌曲讲义按歌名分文件夹，同一首歌可能有初稿、修改稿和终稿。比较表达时留意具体版本，不把不同稿件混为一份。

每个制作过程存档的“本项目存档结构.md”说明该项目的文件作用。例如[太阳升起的舞蹈](讲义制作过程存档/太阳升起的舞蹈/本项目存档结构.md)保留了人机合作的各阶段稿件与修改讨论。

## 查阅时留意

原件中的表达、老师的修改意见和智能体的分析是不同内容。批注不一定已被采纳，一首歌的打法也不代表其它歌曲必须照用。

PDF位置按页码查找；Word正文段号包含空段，不等于打印页码。文字提取不能完整呈现动态图、斜体、删除线和手势图，涉及具体动作时请回看原件。

查询和规则审核的操作见[数据库使用方法](规则与例句数据库/数据库使用方法.md)。
