# 资料说明

这里保存备课参考原件、讲义合作记录，以及从原件提取的表达和修改案例。原件各保留一份；提取内容须注明来源文件与具体位置，不替代原件。

## 目录用途

| 文件夹 | 保存内容 | 怎样使用 |
|---|---|---|
| 教材 | 手语教材原资料，包括句子、会话和语言知识 | 查表达的上下文与教材位置；没有作者解释时，不把AI分析当作教材结论 |
| 小班讲义 | 手语小班的教学讲义 | 学习歌词画面、手语语序、动作表达及讲义制作方法 |
| 优秀讲义 | 已有歌曲讲义原件 | 参考具体转写、图词对应和排版；单独一个表达不代表发生过修改 |
| 人机合作讲义 | 按歌曲保存的对话、各阶段稿件、人工批阅、老师备注稿及打印稿 | 对照一次讲义如何形成，查老师的选择与理由；每首歌的材料范围见其过程说明 |
| 提取与检索 | 原句与手语转写表、修改辨析正文及其检索目录 | 查已有表达，或比较实际修改方案；每条记录指向来源及具体位置 |

[资料目录.xlsx](资料目录.xlsx)记录教材、小班讲义、优秀讲义及人机合作讲义中的原稿、批阅、定稿、对话记录和参考附件，包含日期、作者／授课老师、修订者、资料类型、所属项目和文件链接。一份文件一行，日期未提供的留空，不使用文件时间推断。资料说明、格式要求、候选词条等工作说明不作为原始资料条目。

原句与转写记录只说明“原作者这样表达”；修改辨析须有实际前后方案或明确的修改讨论，并保留老师的理由及出处。辨析目录只放简短检索信息和正文入口，不重复保存Markdown全文。

定位时区分PDF页码、Word正文段落和教材整理文本行号。Word正文段落数包含空段，不是打印页码；PDF提取可能丢失斜体、删除线和图示，需要结合原页核对。

## 提取与检索

三个文件直接放在此目录下：

- [原句与手语转写.xlsx](提取与检索/原句与手语转写.xlsx)：教材和优秀讲义的原句、完整转写、上下文、原文位置和来源链接。用于搜索已有表达，表格是这类提取记录的唯一维护版本。
- [转写修改与辨析.md](提取与检索/转写修改与辨析.md)：实际修改前后方案、老师原话、选择理由及出处，适合连贯阅读。AI归纳单独标明。
- [转写修改与辨析目录.xlsx](提取与检索/转写修改与辨析目录.xlsx)：修改辨析的原句、前后方案摘要、理由来源和正文位置，适合筛选；不复制Markdown完整分析。

原句与转写表可由AI通过`scripts/search_cases.py`检索。查看结果时按来源和位置回看原件，尤其动作方向、非手控、斜体、删除线及图示选择。
