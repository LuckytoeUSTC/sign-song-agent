# 数据库使用方法

可以用[规则与例句查询程序](../规则与例句查询程序.pyw)查询：双击打开后，可搜索关键词、筛选转写规则和来源，点击资料名称用系统默认应用打开原件。

[打开规则与例句查询](../规则与例句查询程序.pyw)

编号速查：`E0001`是转写例句（教材、小班或手语歌讲义中的转写例句）；`太阳-M001`是太阳歌曲的转写辨析案例；`R01`是公共转写规则，`太阳-R01`是本曲转写规则；`D001`是一段教材会话。编号用来找回同一条内容，不随排序改变。其它歌曲用不同的简称。

想知道某句话可以怎么打，打开“转写例句.xlsx”，搜索相近的原句。表中有原转写和原文位置；章节与会话名称也在“原文位置”里。对话中的简答要连着前面的提问读，完整对话在“会话上下文”页。

想知道为什么这样改，打开“转写辨析案例.xlsx”。先看“何时参考”是否像你现在遇到的问题，再看“核心辨析”；觉得有关，就点“查看正文”读老师的理由和完整修改经过。每个案例都保存在对应歌曲的“转写修改与辨析案例”文件夹中。

想找共同经验，读“公共转写规则.md”。规则旁边列出的编号能带你找到相关转写例句。同一句可以有不同的合理打法，参考转写例句或转写辨析案例后仍由老师选择。

你也可以直接告诉智能体：

> 找几个把长句拆成短句的例子，给我看原句、转写和出处。

> 我不确定要不要给两个事物设定左右位置，找相关转写辨析案例，先告诉我哪些值得读。

表中的文字不能完整呈现动态图、斜体和删除线；涉及这些内容时，回看链接中的原件。转写辨析案例正文或开头的引导文字后，请智能体重新生成目录表，避免改两份。

想从一条转写规则找具体实例，在查询窗口选择转写规则；点击转写例句或转写辨析案例上的规则编号也可以反查相关实例。规则正文提及的例子可能是边界或不同用法，需要连着完整说明读。

这里的“数据库”是规则、例句和案例的资料集合，使用 Excel 和 Markdown 查阅，无需数据库软件。规则与例句索引.json 是自动生成的程序数据，手语老师无需打开或维护。
