# 数据库使用方法

[打开规则与例句查询](../规则与例句查询.html)

编号速查：`E0001`是转写例句（教材、小班或优秀讲义中的转写例句）；`太阳-M001`是太阳歌曲的修改案例；`R01`是公共转写规则，`太阳-R01`是本曲转写规则；`D001`是一段教材会话。编号用来找回同一条内容，不随排序改变。其它歌曲用不同的简称。

想知道某句话可以怎么打，打开“转写例句.xlsx”，搜索相近的原句。表中有原转写和原文位置；章节与会话名称也在“原文位置”里。对话中的简答要连着前面的提问读，完整对话在“会话上下文”页。

想知道为什么这样改，打开“转写修改与辨析目录.xlsx”。先看“何时参考”是否像你现在遇到的问题，再看“核心辨析”；觉得有关，就点“查看正文”读老师的理由和完整修改经过。每个案例都保存在对应歌曲的“转写修改与辨析案例”文件夹中。

想找共同经验，读“公共转写规则.md”。规则旁边列出的编号能带你找到相关例子。同一句可以有不同的合理打法，参考案例后仍由老师选择。

你也可以直接告诉智能体：

> 找几个把长句拆成短句的例子，给我看原句、转写和出处。

> 我不确定要不要给两个事物设定左右位置，找相关修改案例，先告诉我哪些值得读。

表中的文字不能完整呈现动态图、斜体和删除线；涉及这些内容时，回看链接中的原件。修改案例正文或开头的引导文字后，请智能体重新生成目录表，避免改两份。

想从一条转写规则找具体实例，打开“规则与例句索引.xlsx”，筛选“转写规则编号”。它同时列出转写例句和修改案例，并给出上下文、简短辨析和原件位置。也可以让智能体直接查 R13 或太阳-R01。关联依据写“规则正文提及”时，只表示规则讨论过这个案例，可能是不同用法或边界，读正文后再判断。索引由智能体从原资料自动更新，不需要老师手工维护第二份。

这里的“数据库”是规则、例句和案例的资料集合，使用 Excel 和 Markdown 查阅，无需数据库软件。在“规则与例句索引.xlsx”表头点筛选箭头，选规则编号即可查看相关实例，选案例编号则可反查规则；点“查看正文／原件”打开详细内容。
