# 手语歌智能工坊 · 下载与配置

版本 **1.0.0**。面向手语老师的手语歌备课智能体工作空间，结合大模型、工作规范与本地工具，辅助理解歌词、讨论转写、查词选图、制作 Word 讲义和检查打印稿。

## 下载

仓库当前为 **private**，下载需要有仓库访问权限。打开 [1.0.0 Release](https://github.com/LuckytoeUSTC/sign-song-agent/releases/tag/v1.0.0)：

| 文件 | 内容 |
| --- | --- |
| `sign-song-agent-v1.0.0.zip` | 完整主包：工作规范、工具、国家通用手语词典、教材、优秀讲义及实际修改案例 |
| `sign-song-agent-dictionaries-v1.0.0.zip` | 其它词典补充包，按需安装 |

解压主包，使用其中的 **手语歌智能工坊** 文件夹。**Code → Download ZIP** 下载仓库中的脚本、说明和教学资料，但不含词典资源。需要已配好国家通用词典的完整项目，请下载 Release 主包。

## 配置智能体客户端

需要支持本地文件读取、Python 执行和图片查看的智能体客户端，例如 Codex。创建本地项目，将“手语歌智能工坊”文件夹设为工作目录。其它客户端也需要读取 `AGENTS.md` 并具备这些工具能力。

客户端账号和模型按客户端要求配置。本项目不内置大模型或独立聊天界面；本地客户端可能调用远程模型服务，按材料允许的使用范围配置权限。只在聊天中发送本机路径不会自动授予文件访问能力。

首次检查可发送：

> 请完整阅读 AGENTS.md，检查本地文件读取、Python、图片查看与国家通用手语词典查询是否可用。Python 或依赖缺失时，请优先自动配置；自动处理失败时先诊断并尝试解决，确实无法完成再说明需要我做的最少操作。不修改讲义。

## Python 与依赖

这一步交给智能体处理，手语老师无需先手动下载安装。

智能体先查找客户端自带或电脑已有的 Python 3.10 及更新版本，优先使用现成运行时。缺少依赖时，自动执行安装命令；缺少 Python 时，尝试自动配置可用运行时。已有满足要求的依赖不重复安装。

自动脚本未能完成时，由模型根据错误诊断、调整方案并继续处理；确实无法自动完成时，再给老师最少的手动步骤。可以直接说：

> 请帮我配置本项目所需的 Python 和依赖。优先使用现有环境并自动处理；失败后先诊断解决，最后才请我手动操作。

工具命令供智能体查阅，见 [工具说明](scripts/TOOLING.md)。通过 Code → Download ZIP 下载时，教学资料已包含在内，词典需另行配置或从完整主包取得。
## 安装词典补充包

1. 解压 `sign-song-agent-dictionaries-v1.0.0.zip`。
2. 按需要选择词典，把它的**整个文件夹**复制到主包的 `手语歌智能工坊/dictionaries/`。
3. 一起保留 MDX、MDD、CSS、图片、视频及其它配套资源，保持词典内部结构；不要只复制 MDX。
4. 若已有同名文件夹，先核对来源和版本，不盲目覆盖。
5. 告诉智能体添加了哪些词典，并检查读取与图片提取是否正常。查词仍优先使用国家通用手语词典。

补充包中的台湾手语词典只保留文字和静态图片，视频已移除；MDX 仍含视频引用，不能据此期待播放视频。需要观看动作时，另用合法取得且含视频的原版。

补充包本身也有 `README.md` 指向本节。
