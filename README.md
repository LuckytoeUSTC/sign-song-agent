# 手语歌智能工坊 · 下载与配置

版本 **1.0.0**。面向手语老师的手语歌备课智能体工作空间，结合大模型、工作规范与本地工具，辅助理解歌词、讨论转写、查词选图、制作 Word 讲义和检查打印稿。

## 下载

仓库当前为 **private**，下载需要有仓库访问权限。打开 [1.0.0 Release](https://github.com/LuckytoeUSTC/sign-song-agent/releases/tag/v1.0.0)，下载 `sign-song-agent-v1.0.0.zip` 并解压。也可以使用 **Code → Download ZIP**。

下载包包含工作规范、脚本、说明、教材、讲义和修改案例。词典资源从云端下载：接管智能体自动准备国家通用手语词典，其它词典由用户选择。可下载词典见 [词典目录](dictionaries/可下载词典.md)。

## 配置智能体客户端

使用支持本地文件读取、Python 执行和图片查看的智能体客户端，例如 Codex。创建本地项目，将解压后的“手语歌智能工坊”文件夹设为工作目录；其它客户端也需要先读取 `AGENTS.md`。

客户端账号和模型按客户端要求配置。本项目不内置大模型或独立聊天界面；本地客户端可能调用远程模型服务，按材料允许的使用范围配置权限。

第一次接管可以说：

> 请完整阅读 AGENTS.md，自动准备 Python、依赖和国家通用手语词典，再告诉我是否可以开始备课。其它词典先列出目录，等我选择。不修改讲义。

## Python 与依赖

这一步交给智能体处理，手语老师无需先手动下载安装。

智能体先查找客户端自带或电脑已有的 Python 3.10 及更新版本，优先使用现成运行时。缺少依赖时自动安装，缺少 Python 时尝试自动配置可用运行时。下载词典的脚本只使用 Python 标准库，无需 AWS CLI、R2 账号或密钥。

自动脚本未能完成时，由模型根据错误诊断、调整方案并继续处理；确实无法自动完成时，再给老师最少的手动步骤。工具命令供智能体查阅，见 [TOOLING.md](scripts/TOOLING.md)。

## 选择其它词典

查看 [可下载词典](dictionaries/可下载词典.md)，直接告诉智能体：“请下载美术常用词通用手语。”智能体会调用脚本，将整套资源放入 `dictionaries` 对应文件夹；已有完整文件不重复下载，未完成的下载可继续。

国家通用词典优先使用。其它专业、历史或地区词典作为有出处的参考，实际选用需结合老师的表达目标。
