# 手语歌智能工坊

面向手语老师的手语歌备课智能体工作空间。结合大模型、工作规范与本地工具，辅助理解歌词、讨论和润色转写、查词选图、制作 Word 图解讲义及检查打印格式。

老师提出教学目标、提供材料并决定操作范围；智能体组织步骤、调用模型与工具，交付可检查的文件；老师审核手语表达与最终讲义。实际能力取决于所接模型、客户端工具、已配置资料和授权范围。

# 手语课备课助手

帮助新老师在备课中学习手语词、语法、表达习惯和文化，并把转写做成清楚的讲义。

## 怎样接入AI

需要能读取本地文件、运行Python工具并查看图片的AI环境。可以使用桌面客户端中的Codex：登录账号，把整个“手语课备课助手”文件夹添加为本地项目的主要文件夹。具体入口见[官方本地项目说明](https://learn.chatgpt.com/docs/projects)。本项目不需要单独接入API或安装专用插件。

第一次打开，可以这样说：

> 请先完整阅读AGENTS.md。检查你能否读取资料、运行scripts中的工具、查询国家通用手语词典并查看图片。先做只读检查，告诉我哪些能力可用、哪些还缺，不修改讲义。

按客户端提示允许必要的本地文件访问和工具执行即可。缺少Python或依赖时，请AI根据scripts/requirements.txt说明或协助配置；不要为了省事开放全部目录权限。用其它AI工具时，也需要这些本地能力，并把AGENTS.md交给它阅读。只上传文件的聊天可以讨论歌词和转写，但仅发送D盘路径不能让它读取本地词典或制作Word。

接入后，告诉助手要做什么。例如：

> 我想教这首歌。请先帮我理解歌词画面，参考教材和优秀讲义，讨论转写，不急着贴图。

> 这是我改过的转写。请按词典选图排版，保留我的注释，另做打印版。

> 请检查老师版与打印版的转写是否一致，以及图片、字号和空格有没有问题。先报告，不改稿。

## 文件放在哪里

- [工作台](工作台/README.md)：正在制作的讲义、各版修改、参考材料和本次讲义格式要求。
- `资料/资料目录.xlsx`：按时间找讲义、筛选转写例子和修改案例；完整内容在原资料或Markdown中。
- [转写修改与辨析](资料/提取与检索/转写修改与辨析.md)：实际修改方案、老师的理由和出处。
- 教材和优秀讲义的转写例子由AI检索，需要时提供原句、上下文和具体位置，手语老师无需通读长篇整理。
- `资料`：教材、小班讲义、优秀讲义；[资料说明](资料/资料说明.md)记录来源及阅读范围。
- `dictionaries`：词典和配套图片、视频资源，国家通用手语词典优先。

- `资料/人机合作讲义`：过去的协作过程，太阳升起的舞蹈是其中一个完整制作案例。
- `AGENTS.md`和`scripts`：AI的工作要求与工具。手语老师不必维护脚本。
- `资料/提取与检索/原句与手语转写.xlsx`：教材和优秀讲义中的原转写及位置，供AI检索，也可自行查阅。

本文件夹为轻量版，附国家通用手语词典及全部配套资源。其它八套词典在“手语课备课助手_词典补充包”；按需把整套词典文件夹复制到这里的`dictionaries`即可，无需维护索引。同名文件夹先确认，不盲目覆盖。

新歌在`工作台`中建同名文件夹即可。先明确哪份是当前稿、要做老师版还是打印版；已有讲义按手语老师的授权局部修改。

一首歌的备课完成后，可以说：“请整理本次对话、关键修改和定稿，收进资料/人机合作讲义/歌题。”保留老师的修改理由和出处，供以后查阅。

增加优秀讲义：放入`资料/优秀讲义`，告诉助手授课或发布日期、手语老师姓名 → 请助手读取正文、必要图示和批注 → 记录有价值的转写例子及位置，有修改理由时另记修改案例。教材没有作者解释的地方，观察和助手分析分开写。

课后可交反馈表或老师自评，请助手提炼具体亮点、困难和建议；填写人数与出席人数分开。需要汇总Excel时提供已有表格。泛泛夸赞不作为改进依据。

交接时复制整个文件夹。资料与词典的使用授权不等于公开传播授权，外发前确认许可。
