# 手语歌智能工坊 · 下载与配置

面向手语老师的手语歌备课智能体工作空间，结合大模型、工作规范与本地工具，辅助理解歌词、讨论转写、查词选图、制作 Word 讲义和检查打印稿。

### 🌟 理想目标

**自动生成稿件不是终点，帮助手语老师在备课中学习手语才是。** 希望每一次讨论、比较和修改，都能让老师多理解一点手语表达。

让拥有基本配置的手语老师，顺利走完从选歌、制作、定稿到反馈的全过程。 **成稿的上限取决于老师的手语水平，而不是计算机操作水平或提示词撰写能力。**

制作能力尽可能少地依赖模型能力，有一个较高的保底水平；最终希望，任意智能体、任何电脑、任何系统，都能达到较高的成稿水平。除了能做出来，成稿也应符合通用的规范。

**随着更多老师参与，希望个人经验也可以经过审核，便捷地汇入共同经验，供以后复用。这是我最想实现的功能，尤其需要大家帮忙！** 提供者可以选择分享一条经验、一个片段或一份讲义，而不是所有个人文件，并决定给谁使用。现有讲义和学习材料也要逐项确认授权，扩大使用范围前征得制作者同意。

目前的项目架构也让更新很费劲：新用户用完整包，老用户用保留兼容代码的覆盖包，两边都要维护；公共资料的更新还要顾及每个人自己的修改。希望以后工具和资料都能方便地更新，个人讲义与经验也能保留。具体怎样实现，我还没有想清楚，需要有人一起研究。

这些目标，靠修补脚本和提示词还远远不够，可能需要几次彻底的架构更新。我一个人的能力做不到，期待有人接力，把工坊继续往前推。

## 下载

在 [v3.1.1发布页面](https://github.com/LuckytoeUSTC/sign-song-agent/releases/tag/v3.1.1) 选择用途和系统。**Windows版已在开发者电脑验证；macOS、Linux版尚未完成实际用户环境测试，欢迎反馈。**

| 你想做什么 | 下载哪类包 | 下一步 |
|---|---|---|
| 接入智能体，完成选歌、转写讨论和讲义制作 | `sign-song-agent-v3.1.1-full-系统后缀` | 解压后打开“手语歌智能工坊”目录，按下文配置智能体 |
| 只查规则、例句、修改辨析和原件 | `no-ai-zone-v3.1.1-系统后缀` | 解压后先读独立README，打开“规则与例句查询”；无需Python或智能体 |
| 更新已有v3.1.0项目 | `sign-song-agent-v3.1.1-update.zip` | 先读“3.1.1更新指导.txt”，由原项目智能体备份、更新并检查；这个旧版覆盖包按Windows环境验证 |

系统后缀：**`windows-x64.zip`**用于Windows 10/11的64位电脑；**`macos-arm64.zip`**用于M系列Mac（macOS 14及以上）；**`linux-x64.tar.gz`**用于Linux x64，基于Ubuntu 22.04构建，其他发行版可能需要补齐图形库。Intel Mac暂未提供对应包。

查询程序随包提供Python运行环境。Windows窗口仍需要WebView2，缺少时按提示补装；Word、PDF原件由相应阅读软件打开。macOS程序尚未签名、公证，首次打开可能需要按系统提示确认来源。完整备课所需的Python和工具依赖由接管智能体另行准备。

**完整包用于新项目，已有项目请先核对更新说明。** 其它旧版本先检查兼容性，保留自己的工作台、资料和词典。

Release的 **Source code** 及 **Code → Download ZIP** 是仓库源码，使用上表中的专门打包附件更方便。

完整版包含工作规范、脚本、说明、教材、讲义和修改案例。词典资源按需下载，见[词典目录](dictionaries/可下载词典.md)。NO-AI-ZONE只保留查询和必要资料，功能与资料均少于完整版，使用原有材料时仍需遵守各自授权范围。

## 配置智能体客户端

本项目使用 Codex 建立，尚未在 DSH、WorkBuddy 中试用。

在支持本机系统的智能体客户端中，将解压后的“手语歌智能工坊”文件夹设为工作目录，并要求智能体先读取 `AGENTS.md`。客户端需要支持本地文件读写、Python执行、图片查看和网络检索；不同系统与客户端的完整备课能力还需继续验证。

客户端账号和模型按客户端要求配置。本项目不内置大模型或独立聊天界面；本地客户端可能调用远程模型服务，按材料允许的使用范围配置权限。

第一次接管可以说：

> 请完整阅读 AGENTS.md，自动准备 Python、依赖和国家通用手语词典，再告诉我是否可以开始备课。其它词典先列出目录，等我选择。不修改讲义。

## Python 与依赖

这一步交给智能体处理，手语老师无需先手动下载安装。

已有Python会优先使用，缺少的环境和依赖由智能体自动准备。词典下载不需要你配置AWS CLI、R2账号或密钥；确实需要你操作时，智能体会说明具体步骤。

## 选择其它词典

查看 [可下载词典](dictionaries/可下载词典.md)，直接告诉智能体：“请下载美术常用词通用手语。”智能体会调用脚本，将整套资源放入 `dictionaries` 对应文件夹；已有完整文件不重复下载，未完成的下载可继续。

国家通用词典优先使用。其它专业、历史或地区词典作为有出处的参考，实际选用需结合老师的表达目标。

## 后续更新与个人资料

目前没有自动更新程序。覆盖更新仅替换发布说明指定的工具和说明，保留个人讲义、工作台、资料库及词典；备份及操作见对应Release。涉及资料或目录结构的完整版本更新，按该版本说明比较差异，不能直接覆盖用户修改，也不要求每次更新都迁移整个项目。

版本号保留已有编号，今后按以下约定递增：第一位表示重大更新（如重构、大量文件更改），第二位表示小幅更新，两者提供完整安装包；第三位表示局部更新，提供覆盖更新包，也可同时提供开发者已整合的完整包，供新用户直接安装。每次Release写明包类型、适用基础版本、覆盖范围与更新办法；历史发布不重编号。

## Codex与人类开发者分工

人类开发者确定需求、使用场景与取舍，提出修改意见并决定发布；手语表达的实际可用性由手语老师判断和试打。Codex按授权编写与整理代码、文档，执行对应包的制作测试和页面检查，并准备发布文件。机器检查不能替代手语判断；发布说明应如实说明已验证内容及限制。

手语老师提供了讲义、教学经验与相关资料，尤其是小班讲义，为工坊的表达讨论和参照学习提供了重要依据。特别感谢二萌老师的资料与教学支持。资料贡献与原创代码的许可分别处理，使用时保留出处。
