# 手语歌智能工坊 · 下载与配置

版本 **1.0.0**。面向手语老师的手语歌备课智能体工作空间，结合大模型、工作规范与本地工具，辅助理解歌词、讨论转写、查词选图、制作 Word 讲义和检查打印稿。

## 下载

仓库当前为 **private**，下载需要有仓库访问权限。打开 [1.0.0 Release](https://github.com/LuckytoeUSTC/sign-song-workshop/releases/tag/v1.0.0)：

| 文件 | 内容 |
| --- | --- |
| `sign-song-workshop-v1.0.0.zip` | 完整主包：工作规范、工具、国家通用手语词典、教材、优秀讲义及实际修改案例 |
| `sign-song-workshop-dictionaries-v1.0.0.zip` | 其它词典补充包，按需安装 |
| `SHA256SUMS.txt` | 两个附件的 SHA-256 校验值 |

解压主包，使用其中的 **手语歌智能工坊** 文件夹。**Code → Download ZIP** 仅下载源码与说明，不含词典和教学资料。

## 配置智能体客户端

需要支持本地文件读取、Python 执行和图片查看的智能体客户端，例如 Codex。创建本地项目，将“手语歌智能工坊”文件夹设为工作目录。其它客户端也需要读取 `AGENTS.md` 并具备这些工具能力。

客户端账号和模型按客户端要求配置。本项目不内置大模型或独立聊天界面；本地客户端可能调用远程模型服务，按材料允许的使用范围配置权限。只在聊天中发送本机路径不会自动授予文件访问能力。

首次检查可发送：

> 请完整阅读 AGENTS.md，检查本地文件读取、Python、图片查看与国家通用手语词典查询是否可用。先做只读检查，列出缺少的依赖、资料或权限，不修改讲义。

## Python 与依赖

提供 Python 3.10 或更新版本，或使用客户端已提供的兼容运行时。在项目目录运行：

```powershell
python -m pip install -r scripts/requirements.txt
```

已有满足要求的依赖时无需重复安装。工具命令见 [工具说明](scripts/工具说明.md)。仅下载源码时，需自行添加获准使用的资料与词典。

## 安装词典补充包

1. 解压 `sign-song-workshop-dictionaries-v1.0.0.zip`。
2. 按需要选择词典，把它的**整个文件夹**复制到主包的 `手语歌智能工坊/dictionaries/`。
3. 一起保留 MDX、MDD、CSS、图片、视频及其它配套资源，保持词典内部结构；不要只复制 MDX。
4. 若已有同名文件夹，先核对来源和版本，不盲目覆盖。
5. 告诉智能体添加了哪些词典，并检查读取与图片提取是否正常。查词仍优先使用国家通用手语词典。

补充包中的台湾手语词典只保留文字和静态图片，视频已移除；MDX 仍含视频引用，不能据此期待播放视频。需要观看动作时，另用合法取得且含视频的原版。

补充包本身也有 `README.md` 指向本节。
