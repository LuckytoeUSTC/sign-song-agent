# 手语歌智能工坊 · 下载与配置

面向手语老师的手语歌备课智能体工作空间，结合大模型、工作规范与本地工具，辅助理解歌词、讨论转写、查词选图、制作 Word 讲义和检查打印稿。

[备课流程图（PDF）](备课流程图.pdf)

## 下载

在 [v3.1.1发布页面](https://github.com/LuckytoeUSTC/sign-song-agent/releases/tag/v3.1.1) 按你的情况下载：

- **第一次使用：**下载 `sign-song-agent-v3.1.1-full.zip`。这是供新项目使用的完整包，无需再应用覆盖更新包。解压后，在智能体客户端中打开“手语歌智能工坊”文件夹，按下面的配置步骤让智能体先读取AGENTS.md、准备环境，再按使用说明开始备课。
- **已有v3.1.0项目：**下载 `sign-song-agent-v3.1.1-update.zip`。解压到原项目之外，先读“3.1.1更新指导.txt”，将其中标明的整段话及更新文件夹路径交给原项目中的智能体，由它备份、覆盖和检查；继续使用原项目，不需要迁移个人资料。其它旧版本先让智能体核对兼容性，不直接覆盖。

Release的**Source code**及**Code → Download ZIP**是仓库源码，不是上述专门打包的附件。完整包与覆盖包二选一。

下载包包含工作规范、脚本、说明、教材、讲义和修改案例。词典资源从云端下载：接管智能体自动准备国家通用手语词典，其它词典由用户选择。可下载词典见 [词典目录](dictionaries/可下载词典.md)。

## 配置智能体客户端

本项目使用 Codex 建立，尚未在 DSH、WorkBuddy 中试用。

在 Codex 中创建本地项目，将解压后的“手语歌智能工坊”文件夹设为工作目录，并要求智能体先读取 `AGENTS.md`。使用其它客户端时，需要支持本地文件读取、Python 执行和图片查看，并先读取 `AGENTS.md`。

客户端账号和模型按客户端要求配置。本项目不内置大模型或独立聊天界面；本地客户端可能调用远程模型服务，按材料允许的使用范围配置权限。

第一次接管可以说：

> 请完整阅读 AGENTS.md，自动准备 Python、依赖和国家通用手语词典，再告诉我是否可以开始备课。其它词典先列出目录，等我选择。不修改讲义。

## Python 与依赖

这一步交给智能体处理，手语老师无需先手动下载安装。

已有Python会优先使用，缺少的环境和依赖由智能体自动准备。词典下载不需要你配置AWS CLI、R2账号或密钥；确实需要你操作时，智能体会说明具体步骤。

## 选择其它词典

查看 [可下载词典](dictionaries/可下载词典.md)，直接告诉智能体：“请下载美术常用词通用手语。”智能体会调用脚本，将整套资源放入 `dictionaries` 对应文件夹；已有完整文件不重复下载，未完成的下载可继续。

国家通用词典优先使用。其它专业、历史或地区词典作为有出处的参考，实际选用需结合老师的表达目标。

## 后续更新与个人资料

目前没有自动更新程序。覆盖更新仅替换发布说明指定的工具和说明，保留个人讲义、工作台、资料库及词典；备份及操作见对应Release。涉及资料或目录结构的完整版本更新，按该版本说明比较差异，不能直接覆盖用户修改，也不要求每次更新都迁移整个项目。

版本号保留已有编号，今后按以下约定递增：第一位表示重大更新（如重构、大量文件更改），第二位表示小幅更新，两者提供完整安装包；第三位表示局部更新，提供覆盖更新包，也可同时提供开发者已整合的完整包，供新用户直接安装。每次Release写明包类型、适用基础版本、覆盖范围与更新办法；历史发布不重编号。

## Codex与人类开发者分工

人类开发者确定需求、使用场景与取舍，提出修改意见并决定发布；手语表达的实际可用性由手语老师判断和试打。Codex按授权编写与整理代码、文档，执行对应包的制作测试和页面检查，并准备发布文件。机器检查不能替代手语判断；发布说明应如实说明已验证内容及限制。

手语老师提供了讲义、教学经验与相关资料，尤其是小班讲义，为工坊的表达讨论和参照学习提供了重要依据。特别感谢二萌老师的资料与教学支持。资料贡献与原创代码的许可分别处理，使用时保留出处。
